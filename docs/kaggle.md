# Kaggle access

API tokens are NOT stored in this repository. Use per-account config directories outside the repo:

- Account `lizaravi` (default): `~/.kaggle/`
- Account `relein`: `KAGGLE_CONFIG_DIR=~/.kaggle_relein kaggle ...`

Never paste a token into any file under this repo (it will be auto-committed). If a token was ever
committed or shared in chat, revoke it on kaggle.com (Settings > API) and generate a new one.
