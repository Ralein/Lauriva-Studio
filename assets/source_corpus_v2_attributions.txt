Offline source corpus: attributions and licences
================================================

assets/source_corpus_v2.bin is a fingerprint-only index: it stores hashed word 4-gram fingerprints,
document titles and URLs. It does NOT contain any source text, so no source passage can be read or
reproduced from it. When a scan matches a source, the app shows the matched passage of the USER's
own text together with the source title and a link to the original page.

Build date 2026-10-06: 62881 documents, 4849162 fingerprints, 205 near-duplicate documents dropped.

Per-document titles and links are stored in the index (doc table) and shown with every match.
The complete per-document list (title, URL, licence) is generated with each build into
tool/corpus/build/attributions_full.tsv (not bundled).
